# Adult Census Income — прогнозирование уровня дохода

## О проекте

Проект решает задачу **бинарной классификации**: по демографическим и социально-экономическим характеристикам человека предсказать, относится ли его годовой доход к категории `>50K` долларов или `<=50K`.

Целевая метрика — **F1-macro**.

## Структура ноутбуков


| Файл                  | Назначение                                                                                                                           |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `EDA.ipynb`           | Первичный анализ данных, распределение таргета, пропуски, числовые и категориальные признаки, корреляции и решения для предобработки |
| `preprocessing.ipynb` | Очистка данных, создание целевой переменной, разделение выборок, кодирование и масштабирование                                       |
| `modeling.ipynb`      | Сравнение baseline, Logistic Regression, Random Forest, SVM, KNN и CatBoost                                                          |
| `FFNN.ipynb`          | Обучение и сравнение двух вариантов полносвязной нейронной сети                                                                      |




## Датасет

Используется **Adult Census Income** — набор данных о взрослых людях с признаками, описывающими возраст, образование, занятость, семейное положение и другие характеристики.

В исходном датасете **32 561 наблюдение и 15 столбцов**, включая целевую переменную `income`.


| Признак          | Описание                                      |
| ---------------- | --------------------------------------------- |
| `age`            | Возраст                                       |
| `workclass`      | Тип занятости                                 |
| `fnlwgt`         | Финальный статистический вес наблюдения       |
| `education`      | Категория образования                         |
| `education.num`  | Числовое представление уровня образования     |
| `marital.status` | Семейное положение                            |
| `occupation`     | Род занятий                                   |
| `relationship`   | Роль в семье относительно главы домохозяйства |
| `race`           | Расовая категория                             |
| `sex`            | Пол                                           |
| `capital.gain`   | Прирост капитала                              |
| `capital.loss`   | Убыток капитала                               |
| `hours.per.week` | Количество рабочих часов в неделю             |
| `native.country` | Страна происхождения                          |
| `income`         | Целевая переменная: `<=50K` или `>50K`        |




### Распределение целевой переменной


| Класс       | Количество | Доля     |
| ----------- | ---------- | -------- |
| `<=50K` (0) | 24 720     | 75.92%   |
| `>50K` (1)  | 7 841      | 24.08%   |
| **Всего**   | **32 561** | **100%** |


Классы распределены неравномерно: класс `<=50K` встречается примерно в три раза чаще. Поэтому для оценки используется именно macro версия метрики f1.

## Основные инсайты EDA

1. **Образование связано с уровнем дохода**: числовой признак `education.num` показал наибольшую корреляцию с целевой переменной среди числовых признаков — около **0.335**. В категориальном анализе доля класса `>50K` увеличивалась с ростом уровня образования; для категорий `Master`, `Doctorate` и `Prof-school` класс высокого дохода становился особенно заметным.
2. **Возраст и рабочая нагрузка тоже связаны с уровнем дохода:** Корреляции с `income` составили около **0.23** для каждого из признаков. По boxplot медианный возраст класса `>50K` был примерно 45 лет против 35 лет у класса `<=50K`. Медиана рабочих часов у высокодоходной группы также была выше.
3. **Прирост и убыток капитала равны нулю у большинства наблюдений:** распределения `capital.gain` и `capital.loss` сильно сосредоточены около нуля, но сами признаки могут оставаться полезными для отдельных наблюдений.
4. **В исходных данных есть пропуски, обозначенные символом** `?`**:** Пропуски в `workclass` и `occupation` совпадали по строкам; их было примерно по 1_800. В `native.country` было около 500 пропусков. В рамках проекта они сохраняются как отдельная категория `Unknown`, а не заменяются наиболее частым значением.
5. `education` **и** `education.num` **дублируют информацию:** В матрице корреляций для них отмечена корреляция 1.0. В предобработке оставлен `education.num`, а `education` удалён.
6. `fnlwgt` **слабо связан с целевой переменной.** Его корреляция с `income` близка к нулю. В анализе признаков связь также оценивалась как практически отсутствующая, поэтому признак удалён.
7. `native.country` **сильно несбалансирован по категориям:** Около 90% наблюдений относятся к США, а остальные страны представлены небольшими долями. Чтобы не создавать множество редких one-hot-признаков, исходный столбец заменён на новый признак `is_usa` со значениями `yes`, `no` и `Unknown`.
8. **Линейной зависимости между признаками и таргетом не выявлено:** Числовые признаки имеют относительно слабые корреляции с target, а числовые распределения неоднородны и содержат выбросы. Это заставляет сравнивать различные модели для решения задачи: линейные, метрические, ансамбли деревьев и нейросети.



## Предобработка и подготовка выборок

В ноутбуке `preprocessing.ipynb` выполнены следующие шаги:

- `income` преобразован в бинарный таргет: `<=50K → 0`, `>50K → 1`
- значения `?` заменены на `Unknown`
- удалены `education` и `fnlwgt`
- `native.country` преобразован в `is_usa`
- данные разделены на train и test в пропорции **80/20** с `random_state=52`
- категориальные признаки закодированы через **One-Hot Encoding** для моделей, которым нужны числовые признаки
- для логистической регрессии, SVM и KNN дополнительно применён `StandardScaler`
- для CatBoost сохранена версия данных с исходными категориальными признаками, поскольку модель умеет работать с ними напрямую



## Подходы и метрики

Для сравнения моделей используются F1-macro, Accuracy, Precision и Recall. Основной метрикой является F1-macro, учитывающая качество классификации обоих классов.


| Подход                     | Особенности подхода                                                                                           | F1-macro | Accuracy | Precision | Recall |
| -------------------------- | ------------------------------------------------------------------------------------------------------------- | -------- | -------- | --------- | ------ |
| DummyClassifier (baseline) | Предсказание наиболее частого класса                                                                          | 0.435    | 0.769    | 0.000     | 0.000  |
| Logistic Regression        | Балансировка классов таргета; стандартизация признаков                                                        | 0.766    | 0.806    | 0.552     | 0.850  |
| Random Forest              | 500 деревьев решений; max_depth = 20; балансировка классов таргета                                            | 0.775    | 0.813    | 0.562     | 0.867  |
| SVM (RBF)                  | Нелинейное RBF-ядро; балансировка классов таргета; стандартизация признаков                                   | 0.763    | 0.801    | 0.545     | 0.863  |
| KNN                        | 7 ближайших соседей; стандартизация признаков                                                                 | 0.772    | 0.843    | 0.678     | 0.613  |
| CatBoost                   | Обработка категориальных признаков; балансировка классов таргета                                              | 0.796    | 0.836    | 0.603     | 0.849  |
| FFNN (один скрытый слой)   | 32 нейрона в скрытом слое; активация - ReLU; оптимизатор Adam; 100 эпох обучения                              | 0.792    | 0.853    | 0.684     | 0.676  |
| FFNN (два скрытых слоя)    | 256 нейронов в первом слое и 64 нейрона во втором слое; активация - ReLU; оптимизатор Adam; 100 эпох обучения | 0.795    | 0.854    | 0.681     | 0.691  |




## Итог и возможное объяснение результатов



### Модели второго эшелона: Logistic Regression, SVM, KNN

Эти три модели показали достойный уровень, но уступили более сильным:


| Модель              | F1-macro | Основное ограничение                                                                                                                                                                                      |
| ------------------- | -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Logistic Regression | 0.766    | Линейная граница не улавливает нелинейные взаимодействия между возрастом, образованием, рабочими часами, семейным положением и профессией. После one-hot-кодирования пространство становится разреженным. |
| SVM (RBF)           | 0.763    | Теоретически может строить нелинейную границу, но чувствительна к выбору гиперпараметров и плохо масштабируется с ростом размерности после one-hot-кодирования.                                           |
| KNN                 | 0.772    | Зависит от метрики расстояния. В многомерном one-hot-пространстве расстояния теряют информативность, а при дисбалансе классов соседи чаще относятся к majority-классу.                                    |




### Random Forest: 0.775

Неплохой результат, но не лучший. Причины:

- Деревья строятся **независимо** и усредняются - в отличие от бустинга, модель не фокусируется на сложных и ошибочных объектах.
- Дисбаланс классов, редкие категории и one-hot-кодирование мешают: при случайном выборе часть деревьев не получает важные признаки.
- Ограничение глубины и усреднение сглаживают вклад отдельных сильных правил.



### Лидеры: CatBoost (0.796) и двухслойная FFNN (0.795)

Разница **0.0003** по F1-macro - в пределах шума, поэтому нельзя утверждать, что одна модель превосходит другую.

**CatBoost** ожидаемо силён:

- градиентный бустинг последовательно исправляет ошибки;
- хорошо работает с табличными данными;
- умеет эффективно обрабатывать категориальные признаки.

**Двухслойная FFNN** подошла к нему вплотную - значит, архитектура смогла уловить основные нелинейные зависимости и взаимодействия признаков.

На данной задаче оба подхода находятся **на одном уровне**. Выбор между ними стоит делать не по F1-macro, а по:

- требованиям к инфраструктуре;
- удобству обучения;
- интерпретируемости;
- скорости.



### Отдельно про нейросети

Даже однослойная FFNN с 32 нейронами показала F1-macro **0.792** — сравнимый с CatBoost, который считается лидером для табличных данных.

Возможные объяснения:

- После one-hot-кодирования и масштабирования признаки становятся удобным числовым представлением, и даже простая полносвязная сеть способна выучить нелинейные комбинации.
- Датасет ~32k записей - достаточно для обучения небольшой сети без сильного переобучения.
- Балансировка классов и оптимизатор Adam помогают сети не игнорировать меньший класс.

**Вывод:** для данной задачи даже относительно простая полносвязная нейронная сеть может быть почти так же эффективна, как сильный бустинг, а усложнение архитектуры само по себе не даёт гарантированного выигрыша.
